The first I’d ever heard about Feedly was from [Linda Stufflebean](https://open.substack.com/users/323342951-linda-stufflebean?utm_source=mentions). She subscribes to “a LOT of genealogy blogs” (see Additional Reading/Viewing), and her inbox was flooded with emails. To avoid that, she uses Feedly. She says “it’s an aggregator—like an electronic file cabinet.” Instead of an email, when a new post goes live, Feedly adds the URL to a list for her to visit when convenient. Kind of like my inbox at Substack, but you can add feeds from more platforms.

## Add Publications

So I signed up for Feedly’s [News Reader](https://feedly.com/i/newAccountSetup/accountTypeUseCase?options), which is free. To add something to my feed, I clicked on Follow Sources and added

```markup
https://YourFamilyQuest.substack.com/feed
```

to the search box. Hit enter. The Substack page popped up, and I clicked Follow.

## Common Mistake

Then I tried adding my website to Feedly. This time, I got a message that I need to “Build RSS Feed.”

![Adding a website to Feedly's free program didn't work because it didn't have RSS.](https://substackcdn.com/image/fetch/$s_!eXON!,w_1456,c_limit,f_webp,q_auto:good,fl_progressive:steep/https%3A%2F%2Fsubstack-post-media.s3.amazonaws.com%2Fpublic%2Fimages%2F283f997e-9a2b-481d-8590-dfd1614f9710_951x494.png)

Adding a website to Feedly's free program didn't work because it didn't have RSS.

Feedly uses RSS (Really Simple Syndication). My website doesn’t have RSS. It doesn’t send out emails, so it can’t be followed on Feedly unless you sign up for the Pro+ subscription. But why would you want to create an RSS feed for my website? I don’t publish anything there, and the only notifications Feedly might post is when I make changes to my site.

## All Substack Publications Have RSS

Remember Karen Foyster featured in my tip, “ *[Substack Has Reserved a Publication Address For You?](https://missiongenealogy.substack.com/p/substack-has-reserved-a-publication)*” I added her to my Feedly even though she has not published any articles on Substack. All I had to do was type:

- https:// **thenameofthepublication**.substack.com/ **feed**.

All Substack publications have RSS, but the secret is that you must use “/ **feed** ” at the end so Feedly can make the connection.
