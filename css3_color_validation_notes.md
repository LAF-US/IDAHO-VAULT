# CSS3 COLOR Validation Notes

RFC 7986 specifies that iCalendar `COLOR` is a TEXT property whose value is a case-insensitive CSS3 color name; it may appear once at VCALENDAR or VEVENT level and is only a presentation hint.[1]

The currently applied values—`white`, `black`, `red`, `orange`, `yellow`, `green`, `blue`, `indigo`, and `violet`—are CSS3 named colors. The optional palette tokens proposed for quarter, senary, and month groups are also selected solely from the CSS3 extended keyword vocabulary.

[1]: https://www.rfc-editor.org/rfc/rfc7986.html "RFC 7986, Section 5.9: COLOR Property"
[2]: https://www.w3.org/TR/css-color-3/ "W3C CSS Color Module Level 3, Section 4.3: Extended Color Keywords"
