# Original Design Analysis (Wayback Machine)

## Key Design Elements Observed:

### Home Page
- Full-width hero image (Idaho Capitol building)
- Large white text overlay on image
- "IDAHO MULTIMEDIA JOURNALIST" as main headline
- White body text with italicized tagline "The world is quiet here."
- Green dashed boxes for buttons (RESUME, WORK)
- Green accent color throughout
- Minimal navigation at top
- Social icons at bottom

### Resume Page
- Clean white background
- "LOGAN FINNEY" header with green dashed border
- Green navigation buttons (RESUME, WORK)
- Large black "EXPERIENCE" section heading
- Content organized in sections with green accents
- Embedded video/media elements
- Detailed work history and education

### Work Page
- White background
- "LOGAN FINNEY" header with green dashed border
- Green navigation buttons
- Large black section headings ("NEWS WRITING", "VIDEO", "AUDIO")
- Organized portfolio content
- Embedded media (YouTube, SoundCloud)
- Links to actual work samples

## Design Language:
- **Colors**: Black, white, green accents (bright neon green)
- **Typography**: Large serif headlines, clean body text
- **Layout**: Centered, spacious, minimal
- **Borders**: Green dashed boxes for emphasis
- **Navigation**: Simple, top-level with green accents
- **Content**: Actual portfolio items, not placeholders

## Current Issues with My Redesign:
- Used blue (#2563eb) instead of green
- Created "Hermes Agent" aesthetic that wasn't in the original
- Added dashed borders everywhere (too much)
- Removed actual portfolio content
- Changed the layout structure significantly
- Lost the clean, editorial feel of the original
