# The Instrument

The vault-game is an instrument. It is work and play at the same time.

It is played, but it produces real output.

## Functions

- Writing instrument: notes, doctrine, lore, reports.
- Governance instrument: review, proof, admission, canon.
- Memory instrument: agent states, recovered payload, source SHAs.
- Game instrument: roles, quests, trials, factions, antagonist pressure.
- Research instrument: source gathering, synthesis, citation, correction.
- Coordination instrument: distributed agents acting without pretending to be
  one continuous mind.

Play is the control surface. A branch is a character because that makes its
payload legible. A PR is a trial because that is how a claim enters the record.
CI is the Verificar because verification is a real gate.

Doctrine line: the instrument makes work playable and play productive.
