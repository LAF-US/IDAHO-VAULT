### Client Libraries

Client libraries to simplify access to the GeoNames [web services](https://www.geonames.org/export/web-services.html) exist in a couple of programming languages.
- [Java Client](https://www.geonames.org/source-code/) developed by the GeoNames team.
- [pgeocode - Python](https://github.com/symerio/pgeocode)
- [Packagist PHP](https://packagist.org/packages/aternus/geonames-client)
- [GeoClue-GeoNames - Ubuntu](https://packages.ubuntu.com/bionic/geoclue-geonames)
- [ES-GEONAMES transform and load with logstash](https://github.com/panchicore/es-geonames/tree/master/logstash)
- [cloudrail](https://cloudrail.com/geonames-api-integration-cloudrail/) Universal API.
- [Objective-C](http://www.infinite-loop.dk/developer/ilgeonames/)
- [GeoNames Ruby API Wrapper](https://github.com/WaKeMaTTa/geo_names/)
- [GeoNames Ruby](http://github.com/elecnix/ruby-geonames) (fork from http://www.tbcn.ca/ruby\_geonames>Ruby Client)
- Drupal:[Drupal Module](http://drupal.org/project/geonames) and [Project Page](http://geonames.edesign.no/)
- [Geocoder - Python](http://geocoder.readthedocs.io/providers/GeoNames.html)
- [geopy - Geocoding Toolbox for Python](http://code.google.com/p/geopy/)
- [Perl GeoNames Client](https://metacpan.org/pod/Geo::GeoNames)
- [Lisp Client](http://code.google.com/p/cl-geonames/)
- [Elixir Client](https://github.com/pareeohnos/geonames-elixir)
- [Pear PHP](http://pear.php.net/package/Services_GeoNames)
- [Leaflet.Geonames](https://github.com/consbio/Leaflet.Geonames)
- [Zend Framework PHP](https://github.com/borisguery/bgylibrary/tree/master/library/Bgy/Service)
- [SOLMETRA Maps (PHP)](http://www.solmetra.com/en/disp.php/en_products/en_scripts/en_maps)
- [Yii (PHP)](http://www.yiiframework.com/extension/egeonameservice/)
- [PHP Laravel](https://packagist.org/packages/michaeldrennen/geonames)
- [R-Project](http://geonames.r-forge.r-project.org/)
- .NET NGeo [sourcecode](https://github.com/danludwig/NGeo) and [NuGet Package](http://nuget.org/packages/NGeo)
- [.NET WCF](http://www.codeproject.com/KB/WCF/GeoNames-WCFClient.aspx)

#### Frameworks

- [Gisgraphy](http://www.gisgraphy.com/): an open source framework for GeoNames data, with importer, geolocalisatoin and fulltext search.
- [NGeoNames](https://github.com/RobThree/NGeoNames):.Net package. provides classes for downloading and parsing files from GeoNames.org and provides (reverse) geocoding methods like NearestNeighbourSearch() and RadialSearch() on the downloaded dataset(s).
