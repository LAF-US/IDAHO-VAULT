Codex Pet is an animated desktop companion feature inside OpenAI Codex that provides real-time visual feedback on AI coding task status. Rather than manually checking logs or dashboards, developers can glance at the floating overlay pet whose animations reflect what the coding agent is doing. The feature addresses a genuine workflow problem: as AI agents run long asynchronous tasks in the background, developers need passive awareness without constant context switching. Users can also customize their pets using AI-generated sprite sheets. The post explores the broader trend of emotional UX design in AI tools, discussing benefits like reduced context switching and higher engagement, alongside risks like distraction and emotional dependency.
