## Bookdown

The bookdown package is an open-source R package that facilitates writing books and long-form articles/reports with R Markdown.

:

People: Yihui Xie

[![Bookdown logo](https://bookdown.org/yihui/bookdown/images/logo.png)](https://bookdown.org/)

## About Bookdown

The **bookdown** package can be added to your R installation to generate multiple format publications (PDF, HTML, Word) from [R Markdown](https://rmarkdown.rstudio.com/) content.

Uses: R Studio; R Markdown; Knitr; TinyTeX; Pandoc.
