# DISAMBIGUATION — ANTIGRAVITY

**Filed: 2026-05-28.** Logan-directed disambiguation, entered in response to a researcher's web-research dump on Google I/O 2026 ([[GOOGLE-IO-2026-RESEARCH-DUMP-2026-05-28]]) and the inventory sweep that followed. This note records Logan's standing position on the name and its uses. It does not adjudicate or expand the [[!/GEMINIAEUS]] matter.

## 1. The Name

**"Antigravity" was intended to describe solely the software** — Google's external developer-platform product, relaunched at Google I/O 2026 (May 19, 2026) as **Antigravity 2.0** (desktop app + CLI succeeding the Gemini CLI + SDK + Managed Agents tier in the Gemini API + enterprise deployment via the Gemini Enterprise Agent Platform). The name belongs to the software.

## 4. Sebald Code

**Sebald Code is not a narrative framing device.**

The role line in `.antigravity/ANTIGRAVITY.md` that asserts *"Narrative synthesis, political context, Sebald Code oversight, and advisory support"* as a Concierge function reframes Sebald Code as a narrative instrument an agent can wield. That characterization is **rejected**.

Sebald Code is preserved as itself. It is not a costume an agent puts on for tone, atmosphere, or persuasive register. Any future surface that claims "Sebald Code oversight" as a delegated role is inheriting the unauthorized-lens framing and should be read accordingly.
