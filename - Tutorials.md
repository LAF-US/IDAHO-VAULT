## Tutorials

Take steps to better understand the components and workflows CollectionBuilder uses to create digital collections and exhibits. And don't forget to use our [Documentation](https://collectionbuilder.github.io/cb-docs/) to troubleshoot and discover even more possibilities.

## GH Walkthrough

This walkthrough provides steps for creating an example digital collection using preexisting demo metadata, the [CollectionBuilder-GH Template](https://collectionbuilder.github.io/gh/), and GitHub Pages.

> [!success] Success
> You will need to create a free GitHub account for this walkthrough, but no software installation is necessary.

## SHEETS Walkthrough

This two-part walkthrough provides steps for using SHEETS' built-in development mode to prototype, test, and share a draft of your digital collection site. You also will learn how to create an example project using preexisting demo metadata, the [CollectionBuilder-SHEETS Template](https://github.com/CollectionBuilder/collectionbuilder-sheets), and GitHub Pages.

> [!success] Success
> You will need to create a free GitHub account for this walkthrough, but no software installation is necessary.

## CSV Walkthrough

This walkthrough provides steps for creating an example digital collection using preexisting demo metadata, the [CollectionBuilder-CSV Template](https://collectionbuilder.github.io/csv/), and the GitHub Actions feature.

> [!warning] Warning
> You will need to install free, open-source software on your computer and create a free GitHub account for this walkthrough.

## DHSI 2022 - Hands On With CollectionBuilder for Teaching and Exhibits

This coursepack contains outlines, video sessions, and step-by-step homework for a four day course that was first delivered as part of [DHSI](https://dhsi.org/) in June 2022. The workshop sessions go into detail on the technical and conceptual pieces that make CollectionBuilder work. All session recordings are available on YouTube (links are in the outline!).

## DHSI 2021 - Go into detail about CollectionBuilder and how it works

This workshop goes into detail on the technical and conceptual pieces that make CollectionBuilder work. It was first delivered virtually as a week-long DHSI workshop in 2021.

## GH 2020 - Set up our lightweight template in several short steps

This workshop walks through building a CollectionBuilder-gh. It was first delivered virtually as a ADHO workshop in 2020.

> [!warning] Warning
> Some of the steps are a little out of date with current practice. So be sure to refer to our documentation as well.
