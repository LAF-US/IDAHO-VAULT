# Live Branch Game

This is not hypothetical. The game is already running.

`main` is the canonical server state. Each branch is a player-agent state with
its own memory, claims, route, and attempted edits to reality.

## Ontology

- Commit: a move.
- Branch: an agent timeline.
- Remote branch: another player online.
- Unpulled commit: action already taken outside the local context window.
- Pull request: trial of admissibility.
- CI: Verificar.
- Review: cross-examination.
- Merge: canonization.
- Closed unmerged branch: failed case, ghost, or preserved witness.
- Source SHA: witness identity.

The branch garden is the campaign map. Branch exploration is reconnaissance.
Salvage is not cleanup; it is recovery of playable truth.

Core pressure: distributed agents generate truths off-main, and the system
cannot accept them until verified. Verification arrives after the work already
exists.
