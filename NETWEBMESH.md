# NETWEBMESH Snapshot

Catalogued on 2026-05-02 by Codex.

## Snapshot

- `NETWEB` is canonical and active as the portable-path standard.
- `MESHWEB` is canonical and active as the runtime portability standard, but still has open implementation items.
- `WEBMESH` exists as a short alias/stub and does not carry separate policy.
- `MESHNET` is represented only indirectly through local node/profile records.
- `NETMESH` and `WEBNET` do not appear as standalone canonical surfaces.
- `NETMESHWEB` is the local node wording used in node/profile records for this machine.

## Boundary Note

The current naming family is split across:

- filesystem portability: `NETWEB`
- runtime portability: `MESHWEB`
- local execution node records: `NETMESHWEB`

Those are related, but they are not interchangeable.
