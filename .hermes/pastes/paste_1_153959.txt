     2. Key Management Endpoints                                                                                                                                                     
     All operations use the /api/v1/keys endpoint and require a Management API key in the Authorization header.                                                                      
     Example Actions:                                                                                                                                                                
     - List keys: GET /api/v1/keys (e.g., openRouter.apiKeys.list()).

     - Delete a key: DELETE /api/v1/keys/{hash}.                                                                                                                                     
                                                                                                                                                                                     
     Response Format:                                                                                                                                                                
     Returns JSON with metadata like created_at, disabled, limit, and usage stats.

     1. Create a new key (e.g., Production Key - Rotated 2026-05).                                                                                                                   
     2. Update applications to use the new key (test in staging first).                                                                                                              
     3. Delete the old key only after confirming the new one works.                                                                                                                  
                                                                                                                                                                                     
     Why? Prevents service interruptions and ensures security compliance.
