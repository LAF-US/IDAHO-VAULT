# ABCD Method

**Adversarial Brownfield Collaboration Dogfood**

ABCD is a working posture for this vault and the agents operating inside it.

- **Adversarial:** assume surfaces can disagree, history can drift, and easy cleanup may destroy evidence.
- **Brownfield:** treat the repository as an inhabited system with strata, not a blank project waiting to be purified.
- **Collaboration:** remember that Logan, agents, plugins, Obsidian, GitHub, and local automation may all be acting on the same substrate.
- **Dogfood:** use the vault itself to test the discipline it describes, in live conditions and with witnesses.

The practical rule is simple: discover first, classify second, touch third. Prefer scoped, reversible changes that preserve both Git history semantics and Obsidian meaning.
