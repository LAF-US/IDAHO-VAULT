# Triangulation — Contextual Positioning Unit

Filed from Logan's phrasing:

> "triangulation" -- Vault R&D re: contextual positioning unit

## Working Definition

Triangulation is a contextual positioning unit: a way to locate meaning, authority, or system state by comparing at least three coordinates rather than trusting a single surface.

In translation, the coordinates may be:

- literal construction
- idiomatic meaning
- cultural temperature

In vault governance, the coordinates may be:

- Logan's direct instruction
- constitutional or doctrine layer
- current transport/runtime/artifact evidence

The point is not averaging. The point is location. A word, command, agent, file, or claim becomes more legible when its position can be inferred from several independent bearings.

## Translation Origin

The working example was *se démerder*:

- literal construction: to de-shit or un-shit oneself
- idiomatic English: figure it out, sort it out, manage somehow
- cultural connotation: practical competence under messy conditions, with little expectation that clean authority will arrive in time

The gap between the French and English does not merely obstruct translation. It reveals the coordinates of meaning. The phrase is not fully contained by either tongue; its position appears in the triangulated space between them.

## Vault Application

Triangulation helps prevent false certainty in agentic systems.

A single signal can lie, drift, or become stale:

- a file can survive after its authority expired
- a runtime can possess technical capability without governance scope
- a registry can lag behind lived system state
- an agent can interpret a phrase correctly in one register and wrongly in another

Triangulation requires the agent to locate the claim against multiple bearings before acting. This is especially important where the same object has several meanings at once: doctrine/artifact, transport/protocol, role/persona, runtime/authority.

## Control Rule

No single surface should be allowed to self-certify high authority when other available coordinates disagree.

For elevated actions, triangulate first:

```text
instruction
-> governance layer
-> live state
-> intended artifact
```

If those bearings do not converge, pause, report the mismatch, and ask Logan or the designated governing surface.
